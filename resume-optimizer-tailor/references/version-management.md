# 简历版本管理

## 目标

帮助用户维护一份真实、完整、可持续更新的简历母本，并基于母本生成不同岗位的定制版本。

## 简历母本

母本不是投递版，而是经历素材库。

应包含：

- 所有工作经历
- 所有项目经历
- 所有可用描述点
- 所有技能、证书、教育经历
- 可选的专业总结版本
- 可选的作品集和案例材料

母本可以较长，不必限制在 1-2 页。

## 定制版本

每个定制版本应说明：

- 目标岗位
- 目标公司
- 目标行业
- 版本语言
- 使用场景：官网投递、猎头沟通、内推、作品集展示、面试携带
- 本版本重点突出的能力

## 命名建议

```text
姓名_岗位方向_公司或行业_语言_日期
```

示例：

```text
张三_AI产品经理_智能制造_中文_2026-07
张三_后端工程师_SaaS_英文_2026-07
张三_客户成功经理_通用版_中文_2026-07
```

## 输出版本说明

每次生成定制简历时，附上：

```markdown
# 版本记录

- 版本名称：
- 基于母本：
- 目标岗位：
- 主要强化：
- 弱化或删除：
- 待用户核实：
```

## 多岗位管理建议

如果用户同时申请多个方向，不要在同一份简历中平均展示所有能力。

建议拆分为：

- 通用母本
- 岗位 A 定制版
- 岗位 B 定制版
- 岗位 C 定制版

每个定制版只突出与目标岗位最相关的经历和能力。
