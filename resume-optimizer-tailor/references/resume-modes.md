# 简历模式

根据用户目标选择一种主模式；必要时可组合使用。

## 1. 通用职场简历

适合大多数白领岗位。重点是岗位匹配、成果表达、结构清晰。

核心模块：

1. 个人信息
2. 专业总结
3. 核心技能
4. 工作经历
5. 项目经历
6. 教育背景
7. 证书/补充信息

## 2. 技术岗简历

适合研发、AI、数据、DevOps、测试、技术产品等岗位。

重点突出：

- 技术栈与岗位 JD 的匹配
- 系统规模、性能、稳定性、成本、自动化等技术成果
- 项目复杂度、架构能力、工程落地能力
- GitHub、作品集、技术博客等链接

## 3. 产品 / 运营 / 市场简历

重点突出：

- 用户增长、转化、留存、收入、活动 ROI 等业务指标
- 需求分析、策略制定、跨部门协作和落地结果
- 对业务问题的判断力，而不是只列工具和执行动作

## 4. 管理岗 / 高管简历

适合经理、总监、VP、C-level 等。

重点突出：

- 团队规模、预算、P&L、业务线规模
- 战略项目、组织建设、流程变革、经营结果
- 领导力品牌和管理风格
- 简历可为 2 页，必要时允许更强的叙事结构

## 5. 应届生 / 实习简历

重点突出：

- 实习、项目、竞赛、课程项目、校园经历
- 与岗位相关的能力证据
- 学习能力、主动性、可迁移技能
- 避免堆砌空泛自我评价

## 6. 转行简历

重点突出：

- 可转移技能
- 过往经历与目标岗位的连接
- 桥梁项目、证书、课程、兼职或侧面项目
- 清楚解释“为什么转”和“为什么能胜任”

## 7. 创意 / 设计简历

重点突出：

- 作品集链接和代表案例
- 视觉层级、审美、品牌一致性
- 可提供“双版本”：ATS 友好版 + 视觉增强版
- 简历本身可以更有设计感，但不能牺牲信息可读性

## 8. 学术 CV

适合教职、研究员、博士后、科研岗位。

重点突出：

- 教育背景
- 研究经历
- 论文、会议、专利、基金、教学、学术服务
- CV 可比职业简历更长，以完整性为优先
