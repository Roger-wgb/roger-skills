# 通用简历视觉风格版本

本文件定义简历的通用风格模式，不只适用于 HTML/CSS。

这些风格可用于：

- Markdown 文本简历
- Word / PDF 排版说明
- HTML/CSS 简历页面
- 作品集页面
- 设计稿提示词
- 打印版简历结构

## 1. 标准专业版

适合：通用白领、运营、项目管理、客户成功、职能岗位。

内容重点：

- 岗位匹配度
- 职责范围
- 业务成果
- 协作能力

视觉特点：

- 白底
- 深灰正文
- 蓝色或墨绿色作为主色
- 顶部信息区 + 清晰模块分割
- 可少量使用技能标签

适合输出：

- 标准文本简历
- Word/PDF 简历
- HTML 简历
- 官网投递优化版

## 2. 技术岗简洁版

适合：研发、AI、数据、DevOps、测试、技术产品。

内容重点：

- 技术栈
- 项目规模
- 系统性能
- 工程复杂度
- GitHub、作品集、技术博客

视觉特点：

- 单栏或弱侧栏
- 技术栈标签清晰
- 项目经历可用卡片结构
- 链接区突出 GitHub、作品集、技术博客

适合输出：

- 技术岗文本简历
- 技术作品集简历
- HTML 技术简历
- 面试官阅读版

## 3. 高管沉稳版

适合：经理、总监、VP、C-level。

内容重点：

- 战略影响力
- 团队规模
- 营收、预算、P&L
- 组织变革
- 关键业务成果

视觉特点：

- 更宽的页边距
- 深色标题
- 少量金色、深蓝或炭黑点缀
- 职业摘要和关键成就前置
- 不使用头像，除非用户明确要求

适合输出：

- 高管猎头版简历
- 董事会/顾问展示版
- 高管 PDF 简历
- 高管 HTML 简历

## 4. 创意设计版

适合：设计、品牌、市场、内容、视频、作品集型岗位。

内容重点：

- 作品集链接
- 代表案例
- 审美与表达能力
- 项目结果
- 个人品牌感

视觉特点：

- 可使用侧栏、头像、品牌色
- 作品集链接显著
- 项目可用案例卡片
- 允许更强的视觉个性，但需保持可读

适合输出：

- 视觉增强版简历
- 作品集页面
- HTML/CSS 简历
- 线下面试展示版

建议同时准备 ATS 友好版。

## 5. 应届生清爽版

适合：应届生、实习、校招。

内容重点：

- 教育背景
- 实习经历
- 项目经历
- 竞赛/奖项
- 学习能力和潜力

视觉特点：

- 清爽、轻量
- 教育背景和项目经历靠前
- 技能、竞赛、实习、校园经历结构清楚
- 可使用浅色块突出核心信息

适合输出：

- 校招简历
- 实习投递简历
- PDF 打印版
- 清爽 HTML 简历

## 6. 双语版

适合：外企、跨国岗位、海外申请、双语工作环境。

内容重点：

- 中英文表达自然
- 目标市场用语准确
- 不机械直译
- 同一经历在双语中保持信息一致

视觉特点：

- 中英文不混乱
- 建议一份中文、一份英文分别输出
- 如必须同页双语，采用模块内双语，而不是逐字并列

适合输出：

- 中文版简历
- 英文版简历
- 双语 PDF
- 双语 HTML 页面
