# 总结生成默认参考

本文件是**默认参考**，供任意支持技能（skill）机制的 AI Agent 在生成"时间段聊天总结"（模式3）或"HTML 报告内嵌总结"（模式2 的一部分）时使用。用户当场给的自定义要求（模式4 / 额外说明）**永远优先于本文件**。

## 数据来源
- 只基于抓到的原文（`raw_chat.txt` 或 `messages.json`），**不臆造、不补全**原文没有的信息。
- 原文里 `me` 是用户自己；其余 sender 是对方（单聊）或群成员。

## 默认结构（Markdown 文本）
先看消息量再决定详略；几十条以内可逐话题说，量大就归纳。

1. **概述**：一句话——和谁 / 哪个群、什么时间、大概聊了什么、整体氛围。
2. **话题与事件线**：按时间列出发生了什么、话题怎么流转；群聊可提关键成员。
3. **要点 / 结论**：聊出了什么共识、决定、结论、下一步；个人私聊可提情绪/状态与关心点。
4. **其他**：值得留存的资料链接、图片/文件提示、红包/转账等事务性事项。

风格：**简洁、信息密度高**，像在给当事人复盘，不写套话、不加"这是一段愉快的交流"之类的废话。

## 自定义要求（模式4）
- 用户说什么就按什么出：只列对方发的链接就只列链接；要合法 JSON 就给 JSON；要表格/英文/周报格式照做。
- 拿不准输出形态时，先问一句再动手。

## 用于 HTML 内嵌
- 交给 `render_html.py --summary` 时，Markdown 或 JSON 均可，脚本会负责排版（Markdown 子集或 JSON 键值 → 小节）。
