# HTML 输出要求

渲染 `report.html` 前，按下面要求校验（借鉴现有"群日报"技能的输出规范，适配到 个人/群 通用场景）。

## 定位
- 不是冷冰冰的统计海报，而是**一份可以回看的事件现场**：发生了什么、谁说的、什么时间、留下了什么资料。
- 单文件、无外部资源、浏览器本地打开即可用；链接可点。

## 必须包含（可核对）
1. **聊天对象明确**：顶部信息卡要有 群名/人名、单聊/群聊 标识、username、区间、消息条数。绝不能让读者猜"这是在聊谁"。
2. **总结区**（给了总结时）：在对话回看之前，用小节组织（概述 / 话题与事件线 / 要点与结论 / 资料…），Markdown 渲染成标题+列表+段落即可。
3. **对话现场**：按天分隔，逐条气泡。发送方可见——`me` 靠右，其余靠左；群聊按成员名着色并显示名字，连续同一人发言不重复刷名字。
4. **消息类型有可读占位**：图片/视频/语音/文件/链接/红包/系统消息分别用带色 chip 标注，保留原文便于核对。
5. **时间和上下文不丢**：每条带时间；内容里的换行保留；链接转成可点 <a>。

## 风格基调（沿用群日报技能观感）
- 纸张米白底（#f3f5ef），白卡片，低饱和强调色（rust/green/blue），正文深灰（#20231f）。
- 版心 ~820px，移动端可用。
- 克制：不堆特效，信息密度优先。

## 边界
- 图片/附件取到的是占位（local_id），本 HTML 只标注、不内嵌媒体文件；需要媒体另跑抓取器的 --media。
